# ARC Engine Router

A lightweight, mobile-first **Arc Network USDC interface** for exploring wallet connections and payment-oriented execution flows.

## Why this project exists

ARC Engine is a product-facing experiment around making blockchain actions easier to understand. The interface combines wallet connection, balance visibility and multiple transaction modes in one focused surface.

## Product surface

- Multi-wallet connection UI
- USDC balance display
- Send / receive / swap / bridge mode structure
- Address and QR-oriented receive flow
- Developer-oriented interaction mode
- Responsive, mobile-first layout
- Arc-focused visual identity

## Stack

- HTML5 / CSS
- Tailwind CSS via CDN
- ethers.js 5.7
- Font Awesome
- Browser wallet APIs

## Run locally

Open `index.html` in a browser or serve the repository with a static web server.

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.

## Important

This repository is an experimental interface. Never enter seed phrases or private keys into a frontend application. Real transaction execution should only be added with explicit network, contract and security validation.
